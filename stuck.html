What to Do When You Are Stuck

A disciplined 5-step engineering escalation procedure. Never spend more than 30 minutes spinning in circles without escalating systematically.

The 5-Step Escalation Ladder

Step 1: Reproduce Minimally (5-10 min)

Strip away web servers, UI widgets, and external wrappers. Isolate the exact failing function into a standalone 10-line Python script or pytest case.

Litmus test: Can you trigger the error predictably with a single command: python repro.py?

Step 2: Read the Official Documentation (5 min)

90% of AI library bugs stem from outdated syntax (e.g. OpenAI SDK v0.28 vs v1.0, Pydantic V1 vs V2, LangChain deprecations). Check the live official docs instead of ChatGPT training data from 2023.

Action: Open the exact method documentation from the Resources Library.

Step 3: Targeted Search (5 min)

Copy the exact innermost exception line from the traceback (strip file paths and memory addresses). Search GitHub Issues on the repository or Google.

Query format: site:github.com/encode/httpx "ExactExceptionName" "FastAPI"

Step 4: Ask AI with a Structured Triage Prompt (5 min)

Do not just type "fix this". Feed the error traceback, minimal repro script, and expected vs observed behavior using our Systematic Debugging prompt.

Copy "Debug Systematically" Prompt →

Step 5: Ask a Human / Community (When 30m Expires)

If 30 minutes pass without resolution, write a clean question for StackOverflow, GitHub Discussions, or Discord. Include: (1) Goal, (2) Minimal code snippet, (3) Full traceback, (4) What you already tried.

Never get stuck alone for more than 45 minutes on a student project.
